## About Confirmo Auth

Confirmo Auth is a gRPC service responsible for authentication, session management, and access enforcement within the Confirmo ecosystem.

## About Confirmo

Confirmo is a secure communication platform designed to protect lawyers and clients from fraud and impersonation.

The platform emphasizes identity verification, controlled access, and structured communication flows to reduce scams and improve trust between parties.

## Techologies

- gRPC
- Apache Kafka
- PostgresSQL
- Rust

## Usage

1. Create a `.env` file based on `.env.example` and set their values.

   ```bash
   cp .env.example .env
   ```

2. Run the server

   ```bash
   cargo run
   ```
