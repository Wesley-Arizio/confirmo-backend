## About Confirmo GraphQL

This project is the entry point for integrating with confirmo services.

## About Confirmo

Confirmo is a secure communication platform built to reduce fraud and impersonation in lawyer–client interactions.

By enforcing identity verification, controlled access, and structured communication flows, Confirmo helps establish trust and prevents common scam scenarios found in informal messaging platforms.

## Techologies

- GraphQL
- gRPC
- PostgresSQL
- Rust

## Usage

1. Create a `.env` file based on `.env.example` and set their values.

   ```bash
   cp .env.example .env
   ```

2. Run the server

   ```bash
   cargo run
   ```
